# Alchemical Bags for Fabric 26.2

Standalone rewrite of ProjectE's Alchemical Bag experience for Minecraft Java 26.2 Fabric.

- 16 colors
- 810 slots per physical bag item (90 rows, matching Huge Storage 90)
- Contents persist inside the item
- Bags cannot be placed inside bags
- Recipe: 3 diamonds, matching wool, chest

This is not ProjectE and provides no EMC or transmutation features.
